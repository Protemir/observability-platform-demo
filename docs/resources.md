# Ресурсы стенда и объём хранения

## Замер на локальном стенде (14.11.2026)

Урезанный стенд: ядро демо 3.1.0 (15 сервисов, без Kafka), генератор нагрузки — 5 HTTP-пользователей,
платформа целиком. Docker Desktop, 28 контейнеров.

| Показатель | Значение |
|---|---|
| Память всех контейнеров | ≈ 2,2 ГБ |
| Активных рядов в Prometheus | ≈ 18 700 |
| Сэмплов в секунду | ≈ 1 060 |
| Журналы в Loki | ≈ 6 строк/с, 3,6 КБ/с |
| Трассы в Tempo | ≈ 17 спанов/с, 9 КБ/с |
| Платформа: Prometheus / Loki / Tempo / Grafana / Collector / Alertmanager | 150 / 130 / 310 / 300 / 140 / 40 МБ |

## Оценка для полного стенда в Kubernetes

Полный демо (с Kafka, accounting, fraud-detection), 10 пользователей нагрузки с браузерными, метрики
узлов и подов (node-exporter, kube-state-metrics, cAdvisor). Закладываем ×5 к замеру по трафику и
+30–40 тыс. рядов инфраструктуры.

| | Оценка | Запас в values |
|---|---|---|
| Prometheus, 7 дней | ~5 000 сэмплов/с × 1,5 Б × 7 дн ≈ 5 ГБ | PVC 20 ГБ, `retentionSize` 18 ГБ, память до 3 ГБ |
| Loki, 7 дней | ~20 КБ/с сырых, сжатие ~10× ≈ 1–2 ГБ | PVC 20 ГБ, память до 1,5 ГБ |
| Tempo, 7 дней | ~45 КБ/с сырых, сжатие ~4× ≈ 7 ГБ | PVC 20 ГБ, память до 2 ГБ |
