# CheckoutLatencySloBurn

**Важность:** warning  
**Сценарии, которые его вызывают:** intlShippingSlowdown, сильная деградация зависимостей

## Что значит

Больше 72 % заказов за час дольше 2 секунд: SLO задержки (95 % быстрее 2 с) сгорает быстро.

## Где смотреть

1. Панель «SLO» → «Доля заказов дольше 2 с».
2. Медленная трасса заказа → самый длинный спан.

## Первые шаги

- Работать по ServiceHighLatency сервиса, который тянет время.

Правило: [alerts/](../alerts/). Панели: Grafana → папка «Observability platform».
