# ServiceHighErrorRate

**Важность:** critical  
**Сценарии, которые его вызывают:** adFailure, cartFailure, paymentFailure, productCatalogFailure (если товар частый)

## Что значит

Больше 5 % входящих запросов сервиса заканчиваются ошибкой дольше минуты.

## Где смотреть

1. Панель «Сервис» для `service` из оповещения: какая операция даёт ошибки («Ошибки по операциям»).
2. Ссылка «Трассы с ошибками за этот период» → открыть 2–3 трассы → найти первый красный спан. Если он в другом сервисе, источник там.
3. В трассе у спана кнопка «Logs for this span» — текст исключения.

## Первые шаги

- Если ошибки начались после выкладки — откатить.
- Если первый красный спан в зависимости — смотреть её оповещение (обычно DependencyCallErrors уже пришло).
- Если ошибки в одном методе и одном аргументе (товар, пользователь) — это данные, а не сервис: OperationErrors.

Правило: [alerts/](../alerts/). Панели: Grafana → папка «Observability platform».
