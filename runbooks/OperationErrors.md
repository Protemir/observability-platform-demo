# OperationErrors

**Важность:** warning  
**Сценарии, которые его вызывают:** productCatalogFailure

## Что значит

Ошибки в одной операции сервиса, когда сервис в целом ещё в норме. Типично: сломан один товар, один маршрут, одна ветка кода.

## Где смотреть

1. Панель «Сервис» → «Ошибки по операциям»: операция из `span_name`.
2. Трассы с ошибкой этой операции → атрибуты спана (id товара, маршрут, аргументы).
3. Журналы спана по trace_id.

## Первые шаги

- Найти общий признак у упавших запросов (один product_id, один клиент).
- Если признак есть — завести задачу владельцу данных/сервиса, оповещение снимется после исправления.

Правило: [alerts/](../alerts/). Панели: Grafana → папка «Observability platform».
