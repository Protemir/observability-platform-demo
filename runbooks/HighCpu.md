# HighCpu

**Важность:** warning  
**Сценарии, которые его вызывают:** adHighCpu

## Что значит

Контейнер использует больше 90 % своего лимита CPU (или больше 1 ядра без лимита) дольше 2 минут.

## Где смотреть

1. Инфраструктура → «CPU контейнеров».
2. Растёт ли одновременно трафик (тогда это нагрузка) или нет (тогда это код).
3. Задержка сервиса: страдают ли пользователи.

## Первые шаги

- Нагрузка — масштабировать (replicas/HPA).
- Нет роста трафика — снять профиль CPU, искать горячий цикл; временно перезапуск.

Правило: [alerts/](../alerts/). Панели: Grafana → папка «Observability platform».
