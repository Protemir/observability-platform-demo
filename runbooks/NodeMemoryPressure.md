# NodeMemoryPressure

**Важность:** warning  
**Сценарии, которые его вызывают:** emailMemoryLeak, recommendationCacheFailure на маленьком кластере

## Что значит

На узле занято больше 90 % памяти дольше 5 минут.

## Где смотреть

1. Инфраструктура → память узлов и контейнеров.

## Первые шаги

- Найти контейнер-лидер по памяти; при утечке — MemoryLeak.
- Если это рост нагрузки — добавить узел.

Правило: [alerts/](../alerts/). Панели: Grafana → папка «Observability platform».
